Marker map

The robot's map of the floor. Nodes are markers, links mean "these two were seen in the same camera frame" — so a link is somewhere the robot can get from one to the other. There are no coordinates and no floor plan: this is a topological map, not SLAM.

1 · Teach it

On the Pi, run the teach loop, then drive the robot round the course with the teleop panel — or just carry it. Walk it past every marker, and pause where two markers are both in view; that is what creates a link. 

sudo systemctl stop medic-nav
cd ~/pi-deploy && .venv/bin/python -m medic.nav --teach

The stop line matters: only one process can hold the camera, so teach mode will not start while the nav service is running.

nav sends no drive commands in this mode — you are the navigation. Stop it with Ctrl-C when you have covered the floor, then put nav back: 

sudo systemctl start medic-nav

2 · Name the new markers

The robot found these but does not know what they are. Name a station for anywhere you can dispatch a delivery to (a room, the pharmacy); name a waypoint for corners and corridor markers that only exist to bridge the gaps.
